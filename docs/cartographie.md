# Cartographie de l'Atelier A1

Notre projet "Visites" repose sur l'architecture suivante :

* **Application :** API en Python (FastAPI / Uvicorn).
* **Base de données :** Instance Redis exécutée dans un conteneur Docker.
* **Environnement d'exécution :** Machine Virtuelle (VM) sous Debian Linux.
* **Gestion de versions :** Git avec hébergement sur GitHub.
